Fabric and Foundry IQ starter knowledge

This deployment provisions one new Microsoft Fabric capacity for two workspaces.
The DEV workspace is connected to an existing GitHub repository, using the
workspace directory on the main branch by default. The TEST workspace starts
empty. The optional cicd configuration promotes Git-versioned Fabric item
definitions to TEST and to a separately provisioned PROD workspace. It does not
copy the underlying data. Derived projects own automated workflows and approvals.

The Microsoft Foundry project connects to a Foundry IQ knowledge base backed by
Azure AI Search. Its indexed OneLake source reads the Files area of the DEV
knowledge lakehouse, including this starter.txt document. No separate Azure
Storage account, private endpoint, or network security perimeter is required.

Azure AI Search uses its managed identity to read OneLake documents and call the
Foundry embedding and chat models. The Foundry project uses its managed identity
to retrieve knowledge through the knowledge-base MCP connection.

Only files in the dedicated knowledge lakehouse are indexed. Other Fabric items,
lakehouses, and the lakehouse Tables area are not part of this knowledge base.
