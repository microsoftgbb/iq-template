# Fabric + Foundry IQ template

A starter for independent **Fabric + Foundry IQ** projects: Terraform infrastructure, Git-versioned Fabric items, a Copilot Studio agent with native IQ tools, a Copilot Managed Runtime app that calls it, and guided Copilot deployment. Derived projects add their scenario workflow; they do not redesign this shell.

## What is where

| Path | Contains |
| --- | --- |
| [`infra/`](infra/) | Terraform: Entra, Fabric, Foundry, Search and knowledge registration. |
| [`workspace/`](workspace/) | Fabric items: lakehouse, seed and bind notebooks, ontology and bootstrap plan. |
| [`agents/scenario-assistant/`](agents/scenario-assistant/README.md) | The Copilot Studio agent: instructions plus its Fabric IQ and Foundry IQ tools. |
| [`app/`](app/) | The Managed Runtime app; [`app/src/config.ts`](app/src/config.ts) holds its only setting. |
| [`generated/`](generated/) | Connector services generated by `ms`; regenerate them, never edit them. |
| `package.json`, `index.html`, `ms.config.json` | Managed Runtime's app root at the repository root; `ms app init` creates `ms.config.json`. |
| `scenario/` | Added by your project: data contracts, documents, workflow rules and evaluations ([contract](docs/scenario-authoring.md)). |
| [`cicd/`](cicd/README.md) | Native Fabric Git bootstrap and promotion. |
| [`docs/`](docs/getting-started.md) | Guides, starting with getting started. |
| [`.github/skills/`](.github/skills/) | Copilot skills that run each workflow. |

The devcontainer includes the [official Azure/Foundry IQ, Work IQ/M365 Agents
Toolkit, Fabric/Fabric IQ and Managed Runtime Copilot packages](docs/copilot-tooling.md).
Installation does not sign in, grant consent or enable optional runtime integrations.

The app reaches DEV through the [proven native runtime route](docs/runtime-integration.md):
app -> Copilot Studio agent -> Fabric IQ ontology and Foundry IQ knowledge base,
each with the signed-in user's own credentials.

one discoverable layout, complete native artifact inventories and fixed
seed/bind/publish/readiness steps. Derived projects supply the scenario rather
than redesigning the platform.

## Get started

1. Select **Use this template** to create your own repository.
2. Open its **Codespace** for the prepared toolchain, or follow [developer setup](docs/development.md) for a local environment.
3. Tell Copilot **"Deploy the platform"**. When using Copilot App with Codespaces, name the Codespace to keep deployment in that checkout and state. It finishes with the agent and app running in the App Player. To skip the agent, run the same [deterministic runner](docs/development.md#deploy-deterministically) yourself: `python3 .github/skills/deploy-platform/scripts/deploy.py up`.

Review [prerequisites and manual steps](docs/getting-started.md) before deploying. You choose the target, sign in, arrange administrator consent and approve the plans. For **configuration only**, use **/initialize-project**.

Use one explicit region by default. Check Fabric CU quota first; the default
serverless Search tier is offered in fewer regions than dedicated tiers, which
also have new-service capacity limits. Approved `fabric_location` /
`search_location` overrides can retain working Foundry resources when a service
is unavailable in that region.

## Scope and boundaries

- **Development baseline:** billable resources, authenticated public endpoints, and preview ontology, deployment-plan and Foundry IQ features.
- **Separate next steps:** TEST starts empty; [native promotion](cicd/README.md) is a separate workflow. PROD, production ingestion, the scenario workflow, hosted app deployment and sharing, and hardening belong to your derived project.
- **Runtime identity:** live ontology retrieval needs an end-user token; managed identity alone is insufficient. See [runtime authentication](docs/ontology-knowledge.md#supply-the-end-users-identity-at-query-time).

The app-facing agent is a standard Copilot Studio agent because the Foundry
Agent Service connector currently fails in Managed Runtime. The knowledge stage
still registers Foundry Fabric IQ connections for that route; see
[routes to re-validate](docs/runtime-integration.md#routes-to-re-validate).

**Template maintainers:** follow [AGENTS.md](AGENTS.md) and enable **Template repository** in GitHub **Settings > General**.
